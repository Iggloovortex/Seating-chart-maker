# Seating-chart-maker
web based, simple, grid to seating chart creator with labeling, icon, and color options.

idea is to choose grid size from 2 separate entry boxes: _ x _

click inside a square to "enable" it as seated. right click to open edit pane to allow labeling, common icons (Tower Desktop, Laptop, human, chair, etc.), rotation of square and elements within (for seats facing not front), and coloring of space, border, fonts (plural, each additional line adds a row for color)

allow me to specify empty row and column height for output, either universally or individually.

give me a button that previews final output

when saved/exported, output seating chart sans grid lines, sized for landscape letter format.

future ability to choose output size either by common paper sizes in dropdown or when choosing custom option, creates entry boxes

future ability to create different sized tables by selecting multiple squares and choosing round or square and stretching the relevant shape to fit. shape should have a transparent spacing/stroke to keep it from touching the border. table should be colorable.
